## v0.9.3 更新内容

### 修复：模组在游戏中无法加载的根因
- **编译失败修复**：删除了 `RealmJudge.RegisterTrueGodEra()` 误调用（该方法从未实现）——这是NML一直编译失败、v0.9.x所有新功能在游戏里"什么都没有"的真正原因，现已修复

### 挑战机制细化
- **同阶逃跑**：挑战者或被挑战者同阶逃跑→逃跑方终身禁赛+回退一阶
- **跨阶逃跑**：跨阶挑战逃跑不回退、不禁赛（侥幸活下来的仍可正常突破）
- **阶位回退机制**：仅登神级及以上可回退——回退后仍无席位则继续作为挑战者挑战，输了没死再回退
- **席位锁死**：软上限=硬上限+3，绝不超过；软上限内单位会攻击席位单位
