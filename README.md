# 基因修炼 (GeneCultivation)

## v0.13.2 圣所放置=真·复刻原单位

- **基因+特质快照**：真神跨存档记录现在保存完整基因序列（nucleus 染色体，含放大器位/空位）与特质快照（登神特质/修炼特质/完美生命）；圣所放置时按原种族生成后重建基因序列（专属亚种，不污染共享亚种）、恢复全部特质——放置出来的不再是"空壳超神"，而是与原单位基因构成一致的真神

## v0.13.1 修复突破登神亚种名不变

- **修复**：突破至使徒级及以上提示"成为独立种族"，但单位面板亚种名仍是 "Homo Sapiensum"（原人类亚种）——`DetachSubspecies` 反射找 `name` **字段**失败（原版 `name` 是 public **属性**）、回退找单参 `setName` 也失败（原版是双参 `setName(string,bool)`），新亚种名从未写入，保留原版 `generateName` 默认名；且复制特质/基因任一步异常会把"切换亚种"一起吞掉。现改为 public 属性直接赋值 + 复制失败不阻断切换（`actor.setSubspecies` 必执行）

## v0.13.0 维度空间世界级改造 + 真神种族修复

- **维度空间 = 真·独立地图**（世界切换，参考机械师模组多世界模式）：进入=备份主世界 → 加载/生成维度空间地图 → 空间居民化身重建（按原种族 asset_id 生成、同 id + custom_data 全量复制）；退出=保存空间 → 加载主世界备份 → 修炼成果写回 → 恢复原存档路径
- **单位随行**：登记的空间居民（12阶+修炼中）进入空间时全部随行，空间内单位真实存在于维度空间地图，可战斗可交互
- **修复**：圣所（跨存档）真神"放置"后不是原种族——保存时 `Race` 硬编码 "Unknown"、放置时随机找现有单位改名改境界；现改为保存真实种族 asset_id、放置按原种族真·生成新单位（旧记录回退随机种族）
- **能量经济/事件/主宰权限**：仅在维度空间地图运行时结算（主地图暂停，返回后继续）

## v0.12.0 维度空间深度深化 + 天赋觉醒联动

- **修复**：进入维度空间后单位仍在地图上——`ds_in_dimension` 状态此前只有图标、注释承诺的"无敌/隐藏/AI暂停"从未实现。现在进入时真隐藏（原版 invincible 无敌 + 反射 is_visible 隐藏 + AI 暂停），退出时恢复
- **能量经济闭环**：空间能量现在有真实产出/消耗——居民每年贡献、主宰注入、等级维持成本、修炼加速消耗；能量不足时修炼加速减半
- **空间事件**：每年随机触发能量潮汐（正）、空间裂缝（负）、入侵者（负），影响能量与居民失控
- **主宰权限**：空间主宰可封禁/解封居民（驱逐+禁止再入）、调控修炼倍率（0.5~3倍循环档位），UI 面板新增对应功能卡
- **天赋觉醒联动**：9阶自动觉醒"觉醒之心"、12阶自动共鸣"基因共鸣"（跨阶天赋加成），本地化中英双语

## v0.11.5 修复跨类裸调用（编译级正解）

- **修复**：`UnitWindowGeneButtonPatch` 类内 3 处 `GetUnitActor(...)` **裸调用**改为 `UnitWindowIntegration.GetUnitActor(...)`——C# 中裸调用不会跨类解析到其他类的静态方法，与访问级别无关（此为 CS0103 真正根因）
